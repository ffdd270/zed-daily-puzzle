# GDScript grammar

The native parser is tree-sitter-gdscript 6.0.0, pinned to
`0b9f60ebaa1c31f5153dd3a3b283ca0725734378` from
<https://github.com/PrestonKnopp/tree-sitter-gdscript> (MIT).
The adjacent configuration and Zed queries are authored for this fork.
Puzzle completion uses the existing isolated Godot language-server worker.
